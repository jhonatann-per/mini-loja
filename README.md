# Mini Loja

Bem-vindo ao projeto **Mini Loja**! Este repositório tem como objetivo treinar e aprimorar nossos conhecimentos no desenvolvimento de um mini-ecommerce. Aqui, vamos explorar diversas funcionalidades essenciais para uma loja virtual, utilizando práticas modernas e design intuitivo.

## Funcionalidades

- **Carrinho de Compras**: Permite aos usuários adicionar produtos ao carrinho e visualizar os itens selecionados.
- **Verificação de CEP**: Os usuários poderão informar o CEP para o envio dos produtos, com validação automática para garantir que o CEP é válido.
- **Lista de Categorias**: Produtos organizados por categorias para facilitar a navegação e a experiência do usuário.
- **Design Moderno e Intuitivo**: Interface do usuário elegante e fácil de usar, focando na melhor experiência possível.

## Tecnologias Utilizadas

- **React** para a construção da interface do usuário.
- **Styled Components** para estilização dos componentes.
- **React Router** para gerenciamento de rotas.
- **API de Produtos** para simulação de dados reais.
